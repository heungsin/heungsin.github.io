# (주)흥신산업 반응형 홈페이지

GitHub Pages에 업로드할 수 있는 순수 HTML/CSS/JS 멀티페이지 홈페이지입니다.

## 사용 방법
1. 이 폴더의 파일 전체를 GitHub 저장소 루트에 업로드합니다.
2. GitHub 저장소의 Settings → Pages → Deploy from a branch → `main` / `/ (root)`를 선택합니다.
3. 고객 문의 폼은 FormSubmit을 통해 `aa-0574@hanmail.net`으로 전달됩니다. 최초 사용 시 FormSubmit에서 도착하는 확인 메일을 한 번 승인해야 합니다.
4. 서버 없이 GitHub Pages에서 동작하도록 구성했으며, 메일 서비스 정책 변경 시 `contact.html`의 form action을 원하는 폼 서비스로 교체할 수 있습니다.

카탈로그 PDF에서 추출한 사진·인증서 이미지가 `assets/img/`에 포함되어 있습니다.
